# Create Fly: Aquatic Ambitions

The Conduit Cage: pump a fluid into it and it ages copper, revives coral, makes prismarine and gives nearby players and mobs effects. No guardian farm needed.

> [!IMPORTANT]
> **This is an unofficial port.** It is not affiliated with or endorsed by
> DaviO. 
> Please report problems here.

## Compatibility

| Component | Version |
| --- | --- |
| Minecraft | `26.1`, `26.1.1` or `26.1.2` |
| Mod loader | Fabric Loader `0.19.3` or newer |
| Create Fly | `6.0.9-4` or newer |
| Fabric API | required |
| Java | `25` or newer |
| Environments | Client and server |

## Download

- [GitHub releases](https://github.com/chaevsfe/create-aquatic-ambitions/releases)


## Building

```
git clone https://github.com/chaevsfe/create-aquatic-ambitions
cd create-aquatic-ambitions
./gradlew build
```

Requires JDK 25.
